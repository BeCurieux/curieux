# cards, over two weeks. Over-index on brands recently hit by an ad disapproval
# and brands selling into the EU, because those two carry the acute version of
# the pain.

# One target per line: a product page URL, then a tab, then why this brand is
# on the list. The "why" is the part that makes the outreach message specific,
# and a target with no "why" is a target that gets a generic DM and a silence
# that teaches nothing.
#
# What is NOT recorded anywhere in this repository: the findings for a named
# brand, or a score for one. BRIEF.md §9 and CLAUDE.md both hold that line —
# these brands have agreed to nothing, and a repository full of graded
# strangers is the Yuka problem with a git history. Scan into a local file
# outside the repo, send the card to the founder, keep the reply in the ledger.
#
# The ledger — killtest/ledger.md, also uncommitted — records only: date,
# brand, contacted how, replied yes/no/silence, asked price, offered to pay.

# Sample photographs

Drop photographs here to see them in the real book layouts.

## How to add them

Easiest route, entirely in a browser — no git required:

1. Go to this folder on GitHub:
   https://github.com/BeCurieux/curieux/tree/claude/childhood-archive-mvp-j5fmet/ordinary-tuesday/sample/photos
2. **Add file → Upload files**
3. Drag the images in
4. **Commit changes** (leave the defaults)

## Formats

**JPG or PNG both work.** For photographs, JPG is the better choice —
a photo saved as PNG is typically 5–10× larger for no visible gain, and
these files travel into a PDF.

## Naming

The name decides where a photo lands in the sample. Anything not matching
one of these is used as a general interior photograph.

| Name it | Where it appears |
|---|---|
| `boots.jpg`   | hero page — full bleed, edge to edge |
| `rabbit.jpg`  | object portrait — small, with white space and a story |
| `hands.jpg`   | the relationship page |
| `bench.jpg`   | two-photo sequence |
| `01.jpg`, `02.jpg` … | ordinary days grid, in order |

## Size

Anything 1500px or wider on its short edge is fine. Smaller images still
work — the system places them at whatever size their resolution honestly
supports rather than enlarging them, so a small photo simply lands smaller
with more space around it.

## What not to put here

No real child's photographs. This folder is committed to the repository
and is not private storage. Real family media only ever lives in the
private Supabase bucket, never in git.

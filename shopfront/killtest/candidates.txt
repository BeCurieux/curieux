# Kill-test candidates — raw, unverified, deliberately over-length.
#
# Run this through the screener on a machine with network access:
#
#   pnpm --silent screen killtest/candidates.txt > killtest/targets.txt
#
# `--silent` is not optional. Without it pnpm writes a two-line banner to stdout
# before the screener runs, the redirect captures it into the targets file, and
# the kill test then refuses to start with a message about duplicate targets
# that names two lines of shell output.
#
# Then edit `targets.txt` by hand: the screener checks feeds, product counts,
# stock and photography, and it decides nothing about whether a merchant is the
# right *kind* of merchant. That judgement is yours and the standard for it is
# in `targets.example.txt`.
#
# ---------------------------------------------------------------- provenance
#
# EVERY LINE HERE IS UNVERIFIED. This file was written in an environment with
# no outbound network — `supabase.com`, `shopify.dev` and every storefront
# return 000 through the egress proxy — so nothing below has been checked
# against reality. It comes from training data, which means:
#
#   · some of these no longer exist, or have been acquired;
#   · some are not on Shopify, or have closed `/products.json`;
#   · some are far outside US$20k–500k/month in either direction;
#   · some now have an in-house developer, which disqualifies them.
#
# That is not an apology, it is the division of labour. Sixty rough names is
# exactly the input `pnpm screen` was written for, and a name that fails is
# commented out rather than dropped so you can reconsider it. What you should
# NOT do is treat this as a contact list and start sending — screen first, then
# apply the standard, then send.
#
# Roughly 70 candidates for a 30-target list, because the screener will reject
# a good third on feed and product count alone, and the standard will cut more.
#
# ------------------------------------------------------------------- balance
#
# Weighted toward the profile rather than toward brands I can name. A list of
# famous DTC brands would be a list of companies with design teams, landing
# pages and a developer — the exact merchant popuup is not for. The ones worth
# the most here are the ones you have half-heard of.
#
# The photography rule matters and cannot be pre-judged from memory: the brief
# asks the renderer to flatter mediocre photography, and thirty catalogues of
# clean studio cut-outs test its easiest case thirty times. `pnpm screen`
# reports a thin-photography flag per store — keep the ones it flags rather
# than dropping them. They are the sample, not the rejects.

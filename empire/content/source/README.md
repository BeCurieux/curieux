# Source documents go here

Put the original Her Little Empire files in this folder (PDF, DOCX, Markdown
or plain text) — one file per product, named as on Gumroad, e.g.
`income-fit-test-v2.pdf`. They are the source of truth for
`content/register.json` and `src/content/methodology.ts`.

Nothing in this folder is served to customers. Keep anything confidential
(customer lists, financials) out of the repository.

When files land here, the conversion steps are in `content/REGISTER.md` →
"Converting a document".

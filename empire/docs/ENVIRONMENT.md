# Environment variables

Validated at startup by `src/env.ts`; a bad combination fails with a message
naming the variable. Set them in Vercel → Project → Settings → Environment
Variables (Production and Preview). Locally, copy `.env.example` to
`.env.local`. Never commit real values.

| Variable                               | Required                       | What it does                                                                                                                                                                                           |
| -------------------------------------- | ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `EMPIRE_BACKEND`                       | yes in production (`supabase`) | `local` (JSON file, email-only sign-in — refused when `VERCEL_ENV=production`) or `supabase`.                                                                                                          |
| `EMPIRE_DATA_DIR`                      | local only                     | Where the local backend keeps its file and uploads. Default `.data/local`.                                                                                                                             |
| `EMPIRE_SESSION_SECRET`                | yes in production              | 32+ random characters. Signs the local session cookie and the Gumroad checkout reference (`empire_ref`). Generate with `openssl rand -base64 48`.                                                      |
| `NEXT_PUBLIC_SUPABASE_URL`             | supabase                       | Project URL.                                                                                                                                                                                           |
| `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | supabase                       | Publishable (anon) key. Safe in the browser; RLS protects data.                                                                                                                                        |
| `SUPABASE_SECRET_KEY`                  | supabase                       | Service-role / secret key. **Server only.** Used for payments, the usage ledger, analytics, model-written generations and account deletion.                                                            |
| `APP_URL`                              | supabase                       | Public URL, e.g. `https://studio.herlittleempire.com`. Sign-in links return here.                                                                                                                      |
| `EMPIRE_AI_PROVIDER`                   | yes                            | `mock` (free, offline, deterministic) or `anthropic`.                                                                                                                                                  |
| `ANTHROPIC_API_KEY`                    | anthropic                      | Server only. Never sent to the browser.                                                                                                                                                                |
| `EMPIRE_AI_MODEL`                      | no                             | Default `claude-opus-5-5`. See `SERVICES.md` for cost trade-offs.                                                                                                                                      |
| `EMPIRE_AI_EFFORT`                     | no                             | `low` (default), `medium` or `high`. Higher is slower and costs more.                                                                                                                                  |
| `EMPIRE_AI_TIMEOUT_MS`                 | no                             | Per-generation timeout. Default 120000.                                                                                                                                                                |
| `EMPIRE_AI_DAILY_BUDGET_USD`           | no                             | Platform-wide ceiling per rolling 24h. New generations pause when reached. Default 25.                                                                                                                 |
| `GUMROAD_PRODUCT_ID`                   | for payments                   | The Launch Pack's Gumroad product id (used to verify licence keys).                                                                                                                                    |
| `GUMROAD_PRODUCT_URL`                  | for payments                   | The Launch Pack's Gumroad link, e.g. `https://herlittleempireco.gumroad.com/l/launch-pack`.                                                                                                            |
| `GUMROAD_PING_SECRET`                  | for payments                   | 24+ random characters, appended to the ping URL as `?token=`.                                                                                                                                          |
| `GUMROAD_ACCESS_TOKEN`                 | recommended                    | Seller API token. Lets us look up sales by id or email — finds older purchases and refunds without licence keys.                                                                                       |
| `CRON_SECRET`                          | for payments and emails        | 24+ characters. Vercel sends it to the daily jobs `/api/billing/recheck` and `/api/email/welcome`.                                                                                                     |
| `NEXT_PUBLIC_INCOME_FIT_TEST_URL`      | no                             | The Income Fit Test's Gumroad link, for the FIT Finder's "get the full report" button. Defaults to https://herlittleempireco.gumroad.com/l/income-fit-test.                                            |
| `NEXT_PUBLIC_LAUNCH_PACK_PRICE_USD`    | no                             | Display price in whole US dollars, no `$` (default 49, shown as US$49). Must match Gumroad.                                                                                                            |
| `EMPIRE_EMAIL_OPTIN`                   | no                             | `on` shows the email opt-in on `/fit-check` (default `off`). In production, `on` requires `RESEND_API_KEY`, `EMAIL_FROM` and `CRON_SECRET` (the app refuses to start without them).                    |
| `RESEND_API_KEY`                       | for welcome emails             | Resend API key with sending access only (docs/launch/WELCOME_EMAILS_SETUP.md). Sensitive. Unset outside Vercel: emails are written to `EMPIRE_DATA_DIR/outbox.jsonl` instead.                          |
| `EMAIL_FROM`                           | for welcome emails             | Sender, e.g. `Vee at Her Little Empire <hello@herlittleempire.com>`. The domain must be verified in Resend.                                                                                            |
| `EMAIL_REPLY_TO`                       | no                             | Where replies go (email 5 asks for them). Default: `hello@herlittleempire.com`.                                                                                                                        |
| `FIT_CHECK_DOWNLOAD_URL`               | no                             | Direct, no-email download of the free Fit Check PDF (e.g. `/downloads/5-question-fit-check.pdf` once the file is added to `public/downloads/`). Unset: `/fit-check` links to the free Gumroad listing. |
| `ADMIN_EMAILS`                         | no                             | Comma-separated emails that can open `/admin`.                                                                                                                                                         |

Note: the generic names `AI_PROVIDER`/`AI_MODEL` are deliberately not used —
other tools on shared hosts set them.
